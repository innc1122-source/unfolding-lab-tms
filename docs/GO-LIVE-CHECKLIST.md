# 上线清单 —— 其间 Unfolding Lab TMS

按顺序做，每项做完打勾。技术细节见 `HANDOVER-IT.md`，后台操作见 `HANDOVER-SSC.md`。

## 阶段 1 —— 部署（IT）

| # | 做什么 | 怎么做 | 通过标准 | ☐ |
|---|---|---|---|---|
| 1.1 | 解压交接包 | 解压到服务器上的固定目录（下文 `<根>`）；**不要**拷演示库 `data\demo-unfolding.db` | `<根>` 下没有 `lms.db` | ☐ |
| 1.2 | 建配置 | 复制 `config.json.example` 为 `config.json`，`production: true`；品牌段已填好，按需改 `publicUrl`、邮件 | `config.json` 不在任何共享盘或代码仓库里 | ☐ |
| 1.3 | 首次启动 | 双击 `start-tms.bat`（或按 IT 篇 2.4 装成 Windows 服务） | 日志里迁移执行到 **99**、没有 `Migration … failed`；窗口里打印了 ADMIN 随机密码 | ☐ |
| 1.4 | 存好 ADMIN 密码 | 首次登录后立即改密，存进密码管理器 | 用新密码能登录后台 | ☐ |
| 1.5 | HTTPS 反向代理 | Nginx / IIS / Caddy，透传 `X-Forwarded-Proto`、`X-Forwarded-Host`（IT 篇 2.5） | 外网只能经 https 访问；直连 8780 端口不对外 | ☐ |
| 1.6 | 外部组件 | 安装 LibreOffice 与 ffmpeg（IT 篇 2.6、2.7） | 后台「课程库 › 课件转换」显示已检测到 | ☐ |
| 1.7 | 备份 | 每日定时运行 `backup.bat`，备份目录在另一块盘或另一台机器（IT 篇第 5 节） | 手动跑一次，`backups\` 里出现当天的快照 | ☐ |

## 阶段 2 —— 组织与人员（HR）

| # | 做什么 | 怎么做 | 通过标准 | ☐ |
|---|---|---|---|---|
| 2.1 | 部门 | 「员工与组织 › 部门」批量导入部门树（「上级 > 子部门」） | 部门树与组织一致 | ☐ |
| 2.2 | 员工 | 「员工档案 › 批量导入」：工号、姓名、部门、职位、职级、入职日期、直属上级、邮箱 | 在职人数与名单一致；结果表里拿到每人的初始密码 | ☐ |
| 2.3 | 一级部门负责人 | 「部门」页逐个指定 | 每个一级部门都有负责人（绩效校准与组织绩效都依赖它） | ☐ |
| 2.4 | 后台角色 | 「系统设置 › 角色与授权」给 HR、培训、绩效管理员分配角色与数据范围 | 每位管理员用自己的账号登录，只看到该看的菜单 | ☐ |
| 2.5 | HRBP 分工 | 「系统设置 › HRBP 分工」 | 每个一级部门都有 HRBP（绩效申诉的处理人） | ☐ |
| 2.6 | 档案与职级 | 「档案与职级设置」：按公司实际改职级体系、晋升条件、绩效评级各档说明 | 职级下拉里是公司自己的职级 | ☐ |

## 阶段 3 —— 内容（培训负责人）

| # | 做什么 | 通过标准 | ☐ |
|---|---|---|---|
| 3.1 | 在「课程库」建课程（或用课程包导入），配好题库与考试 | 用员工账号能完整学完并交卷 | ☐ |
| 3.2 | 建发展项目、期次、活动 | 项目看板数据正常 | ☐ |
| 3.3 | 指派必修课（新增员工不会自动指派） | 员工首页出现「我的课程」 | ☐ |

## 阶段 4 —— 验收（HR + 几位员工）

| # | 走一遍 | ☐ |
