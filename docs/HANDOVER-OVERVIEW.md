# 其间 Unfolding Lab TMS —— 交接总览

更新于 2026-10-12。写给接手这套系统的人：它是什么、包里有什么、怎么开始。操作细节在 IT 篇与 HR 运营篇。

## 一、这个版本是什么

其间 Unfolding Lab 品牌的人才管理系统（TMS），由一套已完成上线验收的企业 TMS 复制而来，做了三件事：

1. **品牌**：名字「其间 / Unfolding Lab」，双圆 logo（深底 / 浅底两版）与 favicon，墨蓝 #23304a + 琥珀金 #eab048 配色（与 unfolding-lab.com 一致）。侧栏当前项用金底墨字。
2. **删除行为实践（Action 3+3 挑战）模块**：模块代码、学员端页面、它的测试与配置全部移除，界面上不再出现任何入口。
3. **去掉原客户专属内容**：Lark 登录与人员同步不再配置；原客户的绩效评级说明文字、课程导入脚本、验收与开发过程文档都已删除。

功能与原系统一致：员工档案、组织架构、培训与考试、发展项目、绩效评估（个人绩效 / 组织绩效两个子模块）、申诉、绩效看板、人才盘点、继任、AI 辅助（缺省关闭）。改动清单见 `RELEASE-CHECKS.md`。

## 四、数据库迁移

首次启动自动建库并执行全部迁移，迁移前自动备份。TMS 迁移最高 **99**（99 = 组织互评结果发布），下一个可用编号 100。迁移 61 在本版本里保留编号但不写任何内容（原为原客户的评级说明）。

## 五、已知限制

- **评级刻度**沿用 A+ / A / B+ / B / C / D：校准名额、上限档、必须写亮点的档位都按这六档写在程序里；各档的说明文字为空，由 HR 在「系统设置 › 档案与职级设置 › 绩效」里填。
- **职级体系**预置通用双通道职级：专业通道 P1–P10、管理通道 M1–M7；职等 D 初级 / C 中级 / B 高级 / A 专家 / E 高管与首席；序号相同即同级（M1≈P4 … M7≈P10）。可在「档案与职级设置 › 职级体系」按公司实际修改。
- **公共假期**内置菲律宾公共假期清单（用于「复核超期」提示），不在菲律宾时在 `config.json` 的 `holidays` 里整份替换。
- **Lark**：登录与人员同步的代码仍在程序里，但本版本不配置、不会运行；登录用工号 + 密码。
- 课件转换依赖服务器上安装 LibreOffice 与 ffmpeg，未安装时 Office 课件不能上传、PPT 内嵌视频不转码（IT 篇 2.6、2.7）。
- 测试：自动化测试全部通过（主系统 1,623 项，1 项按本机环境跳过；计时用例 23 项单独一步）。全量并行运行时 PPT 视频转码的 2 条计时用例可能因机器负载超时，无负载单独复跑通过。
